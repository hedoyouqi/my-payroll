# 급여기록 — 개인 전용 근무·급여 계산 웹앱

네이버 캘린더 없이 날짜별 근무시간을 직접 기록하고 세전·세후 급여를 계산하는 아이폰 홈 화면용 웹앱입니다.

## GitHub Pages 업로드

1. GitHub에서 새 저장소를 만듭니다. 예: `my-payroll` (Public, GitHub Pages 무료 사용 시).
2. 이 폴더의 **파일 전부**를 저장소 최상위(`/`)에 업로드합니다. 폴더 안에 넣지 않고 `index.html`이 바로 보이게 합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
4. 배포 후 `https://사용자명.github.io/my-payroll/` 주소로 접속합니다.
5. 아이폰 Safari의 공유 버튼 → **홈 화면에 추가**를 선택합니다.

> 공개 저장소에 올라가는 것은 웹앱의 코드뿐이며, 입력한 월급/근무 데이터는 기기 브라우저 저장소(localStorage)에만 보관됩니다. **파일 백업은 주기적으로 직접 내려받으세요.** 홈 화면 앱 재설치, 브라우저 데이터 삭제, 기기 변경 등으로 데이터가 사라질 수 있습니다. GitHub Pages 주소를 바꾸면 서로 다른 저장소로 분리될 수 있습니다.

## 입력법

- 달력에서 날짜 클릭 → `8시간`, `10시간`, `특근 8시간`, `유급 8시간`, `휴무` 빠른 선택. 시간이 다르면 숫자를 수정합니다.
- 10시간 일반근무는 기본 8시간 + 연장 2시간으로 계산합니다. 8시간 초과 휴일특근은 `휴일특근 8h 초과` 칸을 사용합니다.
- 야간근로시간은 다른 근로시간에 **추가로 50% 가산**합니다. 이미 가산된 시간과 별도로 야간 기본 시급 전체를 중복 지급하지 않습니다.
- `급여 설정`에서 시급, 수당, 교통비, 보험율, 세액, 주휴 인정 횟수를 수정합니다. 수정한 값은 **해당 달에만** 적용합니다. `이 설정을 기본값으로 저장`하면 이후 월에서도 사용됩니다.
- `급여명세 → 월별 조정`은 명세서와 수치를 맞추기 위한 시간 보정 기능입니다. 미입력 출근일을 보정할 때만 사용하세요. 날짜별 기록과 동일한 시간을 이중으로 더하면 안 됩니다.
- `급여 설정 → 데이터 관리`에서 JSON 내보내기/가져오기 지원합니다.

## 계산 규칙

기본급 = (일반 기본근무시간 + 유급시간) × 시급
주휴수당 = 주휴 인정 횟수 × 주휴 1회당 시간 × 시급
잔업 = 연장시간 × 시급 × 1.5
휴일근로(8시간 이내) = 휴일시간 × 시급 × 1.5
휴일근로(8시간 초과) = 해당 초과시간 × 시급 × 2.0
야간 추가가산 = 야간시간 × 시급 × 0.5
고정수당과 교통비는 매월 지급합계에 더합니다.

4대 보험(2026년 근로자 부담 기본 설정): 국민연금 4.75%, 건강보험 3.595%, 장기요양보험 건강보험료의 13.14%, 고용보험 0.9%. 10월·8월 실제 명세서와 맞도록 국민연금은 보수액 1,000원 미만 절사 후 보험료 10원 미만 절사, 나머지는 보험료 10원 미만 절사합니다. 이 기준은 **관찰한 회사 명세서를 재현하기 위한 근사 규칙**이며 공단의 실제 신고 기준소득월액 및 보수월액과 다를 수 있습니다.

근로소득세: 2026년 간이세액표의 공제대상가족 **1명** 및 월 과세급여 **2,290,000원 ~ 4,700,000원** 범위의 표 값을 내장. 다른 가족 구성이나 이외 급여구간, 기타 비과세·세액공제는 근로소득세를 **직접 입력**해 주세요. 자동 표가 없는 구간은 세금을 0으로 추정하지 않고 `미확정`으로 명확하게 표시하며, 실수령액을 잠정액으로 표시합니다.

주휴 자동 계산은 월~금의 기록이 모두 있고 개근했으며 해당 주의 소정근로시간이 15시간 이상일 때 일요일이 해당 월에 포함된 주만 세는 **참고 추정**입니다. 달력 기록만으로 법정 주휴 자격을 항상 확정할 수 없으므로 회사 명세서에 나온 인정 횟수를 직접 입력하는 방법을 권장합니다.

## 정확성 점검

급여 계산 엔진은 기본급, 주휴, 연장·휴일근로, 보험료, 세금 계산을 기준 명세서와 별도로 교차 검증했습니다. 공개 저장소에 개인 명세서의 전체 급여·공제 금액이 노출되지 않도록 검증 자료는 배포 파일에 포함하지 않았습니다.
